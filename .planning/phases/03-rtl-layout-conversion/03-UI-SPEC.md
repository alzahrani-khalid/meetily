## RTL Conversion Contract

This is the primary visual contract for Phase 3. Every conversion follows the mapping table below.

### Directional Class Mapping (1:1 mechanical replacement)

| Physical Class | Logical Replacement | CSS Property |
|----------------|---------------------|-------------|
| `ml-{n}` | `ms-{n}` | margin-inline-start |
| `mr-{n}` | `me-{n}` | margin-inline-end |
| `pl-{n}` | `ps-{n}` | padding-inline-start |
| `pr-{n}` | `pe-{n}` | padding-inline-end |
| `left-{n}` | `start-{n}` | inset-inline-start |
| `right-{n}` | `end-{n}` | inset-inline-end |
| `-left-{n}` | `-start-{n}` | negative inset-inline-start |
| `-right-{n}` | `-end-{n}` | negative inset-inline-end |
| `text-left` | `text-start` | text-align: start |
| `text-right` | `text-end` | text-align: end |
| `border-l-{n}` | `border-s-{n}` | border-inline-start |
| `border-r-{n}` | `border-e-{n}` | border-inline-end |
| `rounded-l-{n}` | `rounded-s-{n}` | border-radius logical start |
| `rounded-r-{n}` | `rounded-e-{n}` | border-radius logical end |
| `space-x-{n}` | `space-x-{n} rtl:space-x-reverse` | Add companion class |

**Source:** RESEARCH.md Architecture Patterns, Tailwind 3.4.19 docs, spec section 4.3.

### Exceptions (physical classes that MUST stay physical)

| Class | File | Reason |
|-------|------|--------|
| `translate-x-*` | Sidebar/index.tsx | No logical equivalent exists. Branched on `dir` attribute instead. |
| `translate-x-*` | Dialog/sheet centering | Transform centering is direction-independent. |
| Any `rtl:` prefixed class | Various | These ARE the RTL-aware overrides; they are not physical-direction violations. |

Each exception requires an inline `// eslint-disable-next-line no-restricted-syntax` comment with a justification string.

### Sidebar Collapse Animation (UI-06)

| State | LTR (dir="ltr") | RTL (dir="rtl") |
|-------|-----------------|-----------------|
| Expanded | `translate-x-0`, pinned to left edge via `start-0` | `translate-x-0`, pinned to right edge via `start-0` |
| Collapsed | `-translate-x-full` (slides off left edge) | `translate-x-full` (slides off right edge) |
| Collapse button position | Outside right edge of sidebar (`-end-6`) | Outside left edge of sidebar (`-end-6`) |
| Collapse icon (expanded) | `ChevronLeftCircle` (points left = "collapse toward left") | `ChevronRightCircle` (points right = "collapse toward right") |
| Expand icon (collapsed) | `ChevronRightCircle` (points right = "expand from left") | `ChevronLeftCircle` (points left = "expand from right") |

Direction detection method: `useLocale()` from I18nProvider, derive `isRTL = locale === 'ar'`.

**Source:** CONTEXT.md D-08, D-09; RESEARCH.md Pattern 3; spec section 4.4; CLAUDE.md Rule 5.

### BlockNote RTL Spike Visual Contract

The spike test page renders:

| Element | Expected Behavior |
|---------|-------------------|
| Arabic paragraph text | Right-aligned, Tajawal font, correct line wrapping |
| Slash menu (`/`) | Opens with Arabic labels from `ar` dictionary locale |
| Block labels | Displayed in Arabic (paragraph = "فقرة", heading = "عنوان", etc.) |
| Cursor navigation | Arrow keys move correctly in RTL (right-arrow = backward, left-arrow = forward) |
| Editor container | Inherits `dir="rtl"` from parent DOM |
| Font | Tajawal (no Inter font import -- `@blocknote/core/fonts/inter.css` removed) |

Pass bar: ALL 4 questions pass = editable path for SUMM-04. ANY failure = read-only markdown fallback.

**Source:** CONTEXT.md D-01, D-02, D-03; RESEARCH.md Pattern 1.

## ESLint Guardrail Contract (QA-07)

| Property | Value |
|----------|-------|
| Rule | `no-restricted-syntax` |
| Severity | `error` |
