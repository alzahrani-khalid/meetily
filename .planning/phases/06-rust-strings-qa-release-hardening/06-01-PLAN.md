Localize all Rust-owned UI strings (tray menu and system notifications) in Arabic and English, and wire locale-change events so the tray rebuilds when the user switches language.

Output: Bilingual tray menu (13 items), bilingual notifications (12 items), locale-changed event pipeline from preferences write through tray rebuild.
</objective>

   // Listen for future locale changes and rebuild tray

   });
