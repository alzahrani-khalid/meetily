# Phase 6 — UI Design Contract

> Visual and interaction contract for Phase 6: Rust Strings, QA & Release Hardening. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | shadcn |
| Preset | new-york (baseColor: neutral, cssVariables: true) |
| Component library | radix (via shadcn) |
| Icon library | lucide |
| Font (EN) | Source Sans 3 via `next/font/google`, weights 400 + 600 |
| Font (AR) | Tajawal via `next/font/google`, weights 400 + 500 |

**Phase 6 scope note:** This phase adds NO new web UI components. The only new visual surfaces are OS-native tray menus and system notifications, which are rendered by the operating system, not by React/Tailwind. The design contract below documents (1) copywriting for those OS-native surfaces, (2) visual pass/fail criteria for the manual QA-04 regression, and (3) inherited values from prior phases for checker completeness.

### QA-04 Manual RTL Pass/Fail Criteria (D-07, D-08)

| Screen | Pass Criteria |
|--------|--------------|
| Sidebar | No text overflow. Collapse animation slides toward right edge in RTL, left edge in LTR. Active item highlight on correct side. |
| Settings Modal | All labels right-aligned in RTL. Radio groups and switches on correct side. No clipping on Arabic labels (1.2x width factor). |
| Transcript Panel | Timestamps aligned to start edge. Transcript text flows RTL with `writingDirection: rtl`. No horizontal scroll. |
| Summary Panel | BlockNote editor content renders RTL. Template selector labels in Arabic. No overflow on long Arabic headings. |
| Onboarding Flow | All steps right-aligned in RTL. Progress indicator correct direction. CTA buttons full-width, centered text. |
| Tray Menu | All 13 items display in Arabic. No truncation on primary items (Start/Stop/Pause). Emoji prefixes visible. |
| Meeting Details | Meeting name, date, duration labels in Arabic. Action buttons (delete, export) use destructive color correctly. |
