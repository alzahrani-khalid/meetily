**Extend loader.rs `get_template` to accept a `locale` parameter.**

Change signature from `pub fn get_template(template_id: &str)` to `pub fn get_template(template_id: &str, locale: &str)`.

At each tier (custom, bundled, builtin), try the locale-specific file first, then fall back to the base file:

1. **Custom tier** (`load_custom_template`): Add `locale` param. Try `{id}.{locale}.json` first, fall back to `{id}.json`.
```rust
fn load_custom_template(template_id: &str, locale: &str) -> Option<String> {
    let custom_dir = get_custom_templates_dir()?;
    // Try locale-specific first
    let locale_path = custom_dir.join(format!("{}.{}.json", template_id, locale));
    if let Ok(content) = std::fs::read_to_string(&locale_path) {
        info!("Loaded custom template '{}' locale '{}' from {:?}", template_id, locale, locale_path);
        return Some(content);
    }
    // Fall back to base
    let base_path = custom_dir.join(format!("{}.json", template_id));
    std::fs::read_to_string(&base_path).ok()
}
```

2. **Bundled tier** (`load_bundled_template`): Add `locale` param. Same pattern -- try `{id}.{locale}.json` first, fall back to `{id}.json`.

3. **Builtin tier**: Call `defaults::get_builtin_template(template_id, locale)` (updated in Task 1).

4. **`get_template` body**: Thread `locale` through all three tiers.

5. **`list_template_ids`**: When scanning bundled/custom directories, filter out `.ar.json` duplicates -- only return base template IDs (strip `.ar` locale suffix before dedup). The function should return unique template IDs, not locale variants.

6. **`list_templates`**: Accept a `locale` param, pass it through to `get_template(id, locale)` so template names/descriptions match the requested locale.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Custom template dir -> loader | User-crafted JSON files read from filesystem |
| Bundled template dir -> loader | App-bundled JSON files read at runtime |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-01 | Tampering | load_custom_template locale path | mitigate | `format!("{}.{}.json", template_id, locale)` -- both template_id and locale are constrained: template_id comes from a known set, locale is "en" or "ar" from PREFS_CACHE. No user-controlled path traversal possible. Additionally, `serde_json::from_str` + `Template::validate()` rejects malformed content. |
| T-05-02 | Information Disclosure | include_str! paths | accept | Compile-time inclusion -- paths are relative to source file, resolved at build time. No runtime path traversal risk. |
</threat_model>
