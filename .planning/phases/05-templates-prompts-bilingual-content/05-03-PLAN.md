<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| PREFS_CACHE -> pipeline | summary_language value from user preferences drives prompt/template selection |
| Prompt content -> LLM API | Externalized prompt text + user transcript sent to LLM |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-06 | Tampering | summary_language value | mitigate | PREFS_CACHE only accepts "en" or "ar" (Phase 1 invariant). Prompt/template loaders fall back to EN for unknown locales. No path traversal: locale is used as a match arm key, not a file path component in the runtime code path. |
| T-05-07 | Tampering | Named placeholder injection | accept | `{transcript_chunk}` and `{summaries}` are replaced with user transcript content which is already untrusted input to the LLM. The `<transcript_chunk>` and `<user_context>` XML tags provide semantic boundaries for the LLM but are not security controls. This is inherent to LLM-based systems. |
</threat_model>
